# Исходники ЛР №6 (вариант 24 / зачётка 53)

**ФНЧ, окно Кайзера.** Последняя цифра зачётки (3) нечётная, поэтому по таблице 1
методических указаний синтезируется фильтр нижних частот. Порядок `R = 16`,
длина `N = 17`, параметр окна `β = 3,395321052261`.

Оформление и набор пунктов отчёта повторяют образец
`лабораторные/лаба4/Лабораторная работа №4 (вариант 24, зачётка 53).pdf`:
титул, ЦЕЛЬ РАБОТЫ, ИСХОДНЫЕ ДАННЫЕ, ДОМАШНИЙ РАСЧЁТ,
ЭКСПЕРИМЕНТАЛЬНАЯ ЧАСТЬ, ВЫВОД. Лишних разделов нет.
Картинок из «Спектр-2» нет — в отчёте оставлены места под скриншоты.

## Запуск

```bash
cd расчёт/lab6_24_53
python3 calculate.py     # расчёт + проверки -> JSON, CSV, TXT для «Спектр-2»
python3 figures.py       # рисунки 1–3 -> assets/
python3 build_docx.py    # отчёт .docx -> ../../лабораторные/лаба6/
python3 build_pdf.py     # отчёт .pdf  -> ../../лабораторные/лаба6/
```

Зависимости: `numpy scipy matplotlib python-docx reportlab pillow lxml`.
Мини-AST формул (`mathast.py`) используется из родительской папки `расчёт/`.

## Ключевые результаты

```text
Fд = 11200 Гц; F1(ПП) = 1305 Гц; F3(ПЗ) = 2940 Гц; Fc = 2122,5 Гц
fc = 0,189508928571; ΔF = 0,145982142857
amin = 40 дБ; D = 2,231894150418; β = 3,395321052261
R = 16; N = 17; групповая задержка = 8 отсчётов
```

- Максимум в ПЗ `2940…5600 Гц`: `0,009074 ≤ 0,01` (на границе 2940 Гц ослабление 46,452 дБ).
- Диапазон в ПП `0…1305 Гц`: `0,993159…1,008919` при допуске `0,95…1,05`.
- При `R = 14` максимум в ПЗ равен примерно `0,026423 > 0,01`; меньшие чётные порядки тоже не подходят.
- Независимый расчёт `scipy.signal.firwin(..., pass_zero=True, scale=False)` совпал с коэффициентами с ошибкой `1,39·10⁻¹⁷`.
- Контрольный пример ФНЧ из п. 1.2 методички воспроизведён с ошибкой не более `4,73·10⁻⁵` (расхождение только из-за округления до четырёх знаков в таблице).
- Округление коэффициентов до восьми знаков сохраняет выполнение требований.

## Моделирование

АЧХ и ИХ в отчёте получены численным расчётом по коэффициентам фильтра; они не выдаются
за скриншоты «Спектр-2». Для повторения в программе нужны 16 линий задержки, 17 усилителей
и сумматор на 17 входов. Готовые значения коэффициентов и контрольные точки —
в `лабораторные/лаба6/Коэффициенты для Спектр-2 (ЛР6, вариант 24, зачётка 53).txt`.
