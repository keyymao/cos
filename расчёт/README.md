# Исходники расчёта (вариант 12 / зачётка 06)

Скрипты для воспроизводимого расчёта ФВЧ Баттерворта и сборки отчёта `.docx`/`.pdf`.
Готовые файлы работы лежат в корне репозитория.

## Порядок запуска

```bash
cd расчёт
python3 compute_variant.py   # расчёт фильтра -> variant_data.json + печать проверки
python3 figures.py           # рисунки 1–5 -> assets/
python3 build_docx.py        # отчёт .docx (формулы Word/OMML) -> ../
python3 build_pdf.py         # отчёт .pdf (ReportLab)          -> ../
```

## Зависимости

```bash
pip install numpy scipy matplotlib python-docx reportlab pymupdf lxml
```

## Файлы

| Файл | Назначение |
|---|---|
| `calc.py` | движок синтеза: прототип Баттерворта/Чебышёва, замена ФНЧ→ФВЧ, билинейное преобразование, АЧХ, проверка. В `__main__` — валидация на примере методички. |
| `compute_variant.py` | исходные данные варианта 12/06, полный расчёт, проверка, выгрузка в `variant_data.json` |
| `mathast.py` | мини-AST формул: сериализация в OMML (Word) и в inline-разметку (PDF) |
| `content.py` | содержание отчёта (единый источник для .docx и .pdf) |
| `figures.py` | рисунки: схема «Спектр-2», ИХ, АЧХ (лог/лин), проверочный график |
| `build_docx.py` | сборка `.docx` |
| `build_pdf.py` | сборка `.pdf` |
| `variant_data.json` | все вычисленные величины |
| `assets/` | сгенерированные рисунки (встроены в отчёт) |
