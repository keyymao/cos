# Исходники ЛР №6 (вариант 12 / зачётка 06)

Синтез цифрового **ФВЧ методом окна Кайзера**. Порядок фильтра `R = 16`, длина `N = 17`, параметр окна `β = 3,395321052261`. Отчёт оформлен по структуре примера `примеры/лаба4/лаба №4.pdf`, но все числа, коэффициенты и графики рассчитаны заново для варианта 12 / зачётки 06.

## Запуск из корня репозитория

```bash
python3 расчёт/lab6/calculate.py  # расчёт, проверки, JSON/CSV и TXT для «Спектр-2»
python3 расчёт/lab6/figures.py    # 7 рисунков -> расчёт/lab6/assets/
python3 расчёт/lab6/build_docx.py # DOCX -> лабораторные/текущие/лаба6/
python3 расчёт/lab6/build_pdf.py  # PDF  -> лабораторные/текущие/лаба6/

# Доработка загруженного экспериментального отчёта без изменения исходника:
python3 расчёт/lab6/finish_report.py
```

`finish_report.py` создаёт отдельные итоговые файлы в `лабораторные/исправленые/лаба6/`: DOCX с выполненными заданиями №3 и №4 и размеченную экспериментальную АЧХ.

## Зависимости

```bash
pip install numpy scipy matplotlib python-docx reportlab pymupdf pillow lxml
```

`pymupdf` и `pillow` используются для дополнительной проверки PDF и рендеринга страниц; для расчёта нужны прежде всего `numpy` и `scipy`.

## Ключевые данные и проверки

```text
Fд = 10600 Гц
F1(ПП) = 2520 Гц, F3(ПЗ) = 1005 Гц, Fc = 1762,5 Гц
fc = 0,166273584906; ΔF = 0,142924528302
amin = 40 дБ; D = 2,231894150418; β = 3,395321052261
R = 16; N = 17; групповая задержка = 8 отсчётов
```

- Максимум в ПЗ: `0,009669005 ≤ 0,01` (`40,292364 дБ` на границе 1005 Гц).
- Диапазон в ПП: `0,990391456…1,005886154` при допуске `0,95…1,05`.
- При `R = 14` максимум в ПЗ равен примерно `0,030511 > 0,01`; все меньшие чётные порядки также не подходят.
- Независимый расчёт `scipy.signal.firwin(..., pass_zero="highpass", scale=False)` совпал с коэффициентами с ошибкой `1,086·10⁻¹⁶`.
- Контрольный пример ФВЧ из п. 1.3 методички воспроизведён с ошибкой не более `4,73·10⁻⁵` относительно опубликованных значений, округлённых до четырёх знаков.
- Округление коэффициентов до восьми знаков сохраняет выполнение требований.

## Границы по экспериментальной АЧХ

Точные пересечения расчётной характеристики, совпадающей по форме со скриншотом:

- `|H| = 0,01`: `f₃ = 1007,1214 Гц` (`+2,1214 Гц` относительно `F₃`);
- `|H| = 0,95`: `f₁ = 2360,4769 Гц` (`−159,5231 Гц` относительно `F₁`);
- `|H| = 0,5`: `1762,1880 Гц`, практически `Fc = 1762,5 Гц`.

Скриншот «Спектр-2» получен при шкале, соответствующей `Fд ≈ 48000 Гц`, а не заданным `10600 Гц`: зелёный курсор показывает `11,086 кГц`. В итоговом отчёте экранные частоты делятся на `48000/10600 ≈ 4,528`, поэтому отметки `4,56`, `7,98` и `10,69 кГц` соответствуют проектным частотам `1007`, `1762` и `2360 Гц`.

## Моделирование

В отчёте, создаваемом `build_docx.py`, АЧХ и ИХ получены численно по коэффициентам фильтра: это расчётный эталон, который **не выдаётся за скриншоты «Спектр-2»**. Скрипт `finish_report.py`, напротив, сохраняет реальные экспериментальные изображения из загруженного DOCX и только добавляет к АЧХ проверенную разметку. Для повторения работы в программе нужны 16 линий задержки, 17 усилителей и сумматор на 17 входов. Готовые значения усилителей и контрольные точки находятся в `лабораторные/текущие/лаба6/Коэффициенты для Спектр-2 (ЛР6, вариант 12, зачётка 06).txt`.
