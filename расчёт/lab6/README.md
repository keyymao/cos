# Исходники ЛР №6 (вариант 12 / зачётка 06)

Синтез цифрового **ФВЧ методом окна Кайзера**. Порядок фильтра `R = 16`, длина `N = 17`, параметр окна `β = 3,395321052261`. Отчёт оформлен по структуре примера `примеры/лаба4/лаба №4.pdf`, но все числа, коэффициенты и графики рассчитаны заново для варианта 12 / зачётки 06.

## Запуск из корня репозитория

```bash
python3 расчёт/lab6/calculate.py  # расчёт, проверки, JSON/CSV и TXT для «Спектр-2»
python3 расчёт/lab6/figures.py    # 7 рисунков -> расчёт/lab6/assets/
python3 расчёт/lab6/build_docx.py # DOCX -> лабораторные/лаба6/
python3 расчёт/lab6/build_pdf.py  # PDF  -> лабораторные/лаба6/
```

## Зависимости

```bash
pip install numpy scipy matplotlib python-docx reportlab pymupdf pillow lxml
```

`pymupdf` и `pillow` используются для дополнительной проверки PDF и рендеринга страниц; для расчёта нужны прежде всего `numpy` и `scipy`.

## Ключевые данные и проверки

```text
Fд = 10600 Гц
F1(ПП) = 2520 Гц, F3(ПЗ) = 1005 Гц, Fc = 1762,5 Гц
fc = 0,166273584906; ΔF = 0,142924528302
amin = 40 дБ; D = 2,231894150418; β = 3,395321052261
R = 16; N = 17; групповая задержка = 8 отсчётов
```

- Максимум в ПЗ: `0,009669005 ≤ 0,01` (`40,292364 дБ` на границе 1005 Гц).
- Диапазон в ПП: `0,990391456…1,005886154` при допуске `0,95…1,05`.
- При `R = 14` максимум в ПЗ равен примерно `0,030511 > 0,01`; все меньшие чётные порядки также не подходят.
- Независимый расчёт `scipy.signal.firwin(..., pass_zero="highpass", scale=False)` совпал с коэффициентами с ошибкой `1,086·10⁻¹⁶`.
- Контрольный пример ФВЧ из п. 1.3 методички воспроизведён с ошибкой не более `4,73·10⁻⁵` относительно опубликованных значений, округлённых до четырёх знаков.
- Округление коэффициентов до восьми знаков сохраняет выполнение требований.

## Моделирование

АЧХ и ИХ в отчёте получены численно по коэффициентам фильтра. Они являются расчётным эталоном и **не выдаются за скриншоты «Спектр-2»**. Для повторения работы в программе нужны 16 линий задержки, 17 усилителей и сумматор на 17 входов. Готовые значения усилителей и контрольные точки находятся в `лабораторные/лаба6/Коэффициенты для Спектр-2 (ЛР6, вариант 12, зачётка 06).txt`.
