# Разметка АЧХ ЛР №3 и №4 — вариант 12 / зачётка 06

Скрипт [`annotate_reports.py`](annotate_reports.py) дорабатывает два загруженных отчёта:

- ЛР №3: заменяет рисунки 3 и 4 размеченными логарифмической и линейной АЧХ;
- ЛР №4: заменяет рисунки 2 и 3, исправляет порядок названий масштабов в тексте и добавляет экспериментальное задание №3 перед контрольными вопросами.

Исходные файлы в `лабораторные/текущие/` не изменяются. Результаты записываются в соответствующие папки `лабораторные/исправленые/`.

## Запуск

```bash
python3 -m pip install pillow
python3 расчёт/variant12_06/annotate_reports.py
```

## Контрольные значения

### ЛР №3 — без предыскажения

- `f₁ = 2993,7 Гц`, `a = 0,4455 дБ` — граница ПП цифрового ФВЧ;
- `f₃ = 1380,8 Гц`, `a ≈ 40,08 дБ` — граница ПЗ цифрового ФВЧ;
- уровни линейной АЧХ: `|H| ≈ 0,95` и `|H| = 0,01`.

### ЛР №4 — с предыскажением

- `f₁ = 3740 Гц`, `a = 0,4455 дБ` — граница ПП, совпавшая с `F₁` по ТЗ;
- `f₃ ≈ 1943 Гц`, `a = 40 дБ` — фактическая граница ПЗ по контрольному уровню;
- `F₃ = 1440 Гц` по ТЗ лежит внутри ПЗ; на ней `a ≈ 57,70 дБ`;
- запас по подавлению на `1440 Гц` составляет `17,70 дБ`.

На иллюстрациях ПП показана синим, ПЗ — красным, а заданная граница `F₃` для ЛР №4 — пунктирной линией цвета охры. Подписи содержат только готовые значения без развёрнутых вычислений ослабления.
