# Отметки АЧХ для ЛР №3, вариант 24 / зачётка 53

Здесь находятся два небольших воспроизводимых скрипта для доработки загруженного отчёта.

## Что делают скрипты

- `annotate_report.py` извлекает два скриншота АЧХ из DOCX, наносит отметки и создаёт **копию** отчёта в `лабораторные/исправленые/лаба3/`. Исходный DOCX из `текущие/` не изменяется.
- `plot_achx.py` рассчитывает АЧХ по коэффициентам таблицы 3 и строит два чистых эталонных графика с теми же отметками.

## Отмечаемые величины

| Величина | Значение |
|---|---:|
| Граница полосы пропускания ЦФ после билинейного преобразования | `f₁ = 2074,6 Гц` |
| Граница полосы задержания ЦФ после билинейного преобразования | `f₃ = 3173,3 Гц` |
| Минимальный допустимый модуль в ПП | `10^(−0,4455/20) = 0,950003 ≈ 0,95` |
| Максимальный допустимый модуль в ПЗ | `10^(−40/20) = 0,01` |

Важно: на экспериментальных графиках отмечаются именно частоты цифрового фильтра `2074,6` и `3173,3 Гц` из раздела 1.8, а не исходные частоты аналогового прототипа `2220` и `3760 Гц`.

## Запуск

Из корня репозитория:

```bash
python3 -m pip install pillow numpy matplotlib
python3 расчёт/lab3_24_53/annotate_report.py
python3 расчёт/lab3_24_53/plot_achx.py
```

Папку результата можно изменить параметром `--output-dir`. Для `annotate_report.py` также можно явно указать документ параметром `--source`.

## Проверочные значения

По округлённым коэффициентам отчёта:

```text
f₁ = 2074,6 Гц: |H| = 0,9501175; a = 0,4445 дБ
f₃ = 3173,3 Гц: |H| = 0,0074028; a = 42,6121 дБ
```

Оба требования выполняются: в ПП ослабление не превышает `0,4455 дБ`, а в ПЗ превышает требуемые `40 дБ`.
