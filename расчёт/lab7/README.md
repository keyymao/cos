# Исходники ЛР №7 (вариант 12 / зачётка 06)

ДПФ и БПФ Кули–Тьюки с прореживанием по времени. Отчёт оформлен по структуре примера `примеры/лаба5/лаба №5.pdf` и требованиям `лабораторные/лаба7/LR_TsOS_7_DPF.pdf`; все коэффициенты, спектры и рисунки рассчитаны заново для варианта 12 / зачётки 06.

## Запуск из корня репозитория

```bash
python3 расчёт/lab7/calculate.py  # ДПФ/БПФ, проверки, JSON/CSV и TXT
python3 расчёт/lab7/figures.py    # 8 рисунков -> расчёт/lab7/assets/
python3 расчёт/lab7/build_docx.py # DOCX -> лабораторные/лаба7/
python3 расчёт/lab7/build_pdf.py  # PDF  -> лабораторные/лаба7/
```

## Зависимости

```bash
pip install numpy scipy matplotlib python-docx reportlab pymupdf pillow lxml
```

`numpy` используется для независимого контроля, `scipy.signal.spectrogram` — для спектрограммы. `pymupdf` и `pillow` нужны для визуальной проверки готового PDF.

## Файлы

| Файл | Назначение |
|---|---|
| `calculate.py` | Прямое ДПФ, рекурсивное БПФ, промежуточные последовательности, гармоники и прямоугольный импульс |

Общий модуль формул `mathast.py` находится в родительской папке `расчёт/`.

## Проверки и согласования

- Прямое матричное ДПФ и рекурсивное БПФ сравниваются с `numpy.fft.fft`; максимальные расхождения — `3,79·10⁻¹⁵` и `1,11·10⁻¹⁶`.
- Аналитические коэффициенты ДПФ-8, обратное ДПФ, сопряжённая симметрия и все четыре операции объединения последнего этапа проверяются утверждениями в `calculate.py`.
- Для гармоник проверяется `|X(m)| = |X(N−m)| = AN/2`; вне расчётных пиков остаются только ошибки округления.
- Раздельно рассчитаны режимы второй ветви `K2 = 0`, `K2 = 1` (амплитуда `A2 = 2,24` из варианта) и `K2 = 4` (практический пункт методички). Это исключает неоднозначное сложение амплитуды варианта с дополнительным усилением.
- Для прямоугольного импульса проверяются `X(0) = 16`, нули `k = 64m` и равенство Парсеваля.

Графики в отчёте — **численный расчётный эталон, а не скриншоты «Спектр-2»**. Контрольные значения для повторения схемы находятся в `лабораторные/лаба7/Параметры для Спектр-2 (ЛР7, вариант 12, зачётка 06).txt`.
