# Исходники ЛР №4 (вариант 24 / зачётка 53)

**ФНЧ Чебышёва, n = 6.** Аналоговый ФНЧ-прототип взят из готовой ЛР №3
(вариант 24 / зачётка 53) и переведён в цифровой фильтр преобразованием
Константинидиса для ФНЧ с предыскажением:

```
p = ctg(π F1/Fд) · (1 − z⁻¹)/(1 + z⁻¹) = 1,96261 · (1 − z⁻¹)/(1 + z⁻¹)
```

Оформление и набор пунктов отчёта повторяют образец `лаба №3.pdf`:
титул, ЦЕЛЬ РАБОТЫ, ИСХОДНЫЕ ДАННЫЕ, ДОМАШНИЙ РАСЧЁТ,
ЭКСПЕРИМЕНТАЛЬНАЯ ЧАСТЬ, ВЫВОД. Лишних разделов нет.
Картинки из «Спектр-2» не рисуются — в отчёте оставлены места под скриншоты;
все коэффициенты для сборки схемы вынесены в отдельный TXT в корне репозитория.

## Запуск

```bash
cd расчёт/lab4_24_53
python3 calculate.py     # расчёт + проверки -> JSON, TXT для «Спектр-2»
python3 build_docx.py    # отчёт .docx в корень репозитория
python3 build_pdf.py     # отчёт .pdf в корень репозитория
```

Зависимости: `numpy scipy python-docx reportlab matplotlib lxml`.
Мини-AST формул (`mathast.py`) используется из родительской папки `расчёт/`.
