## Почему максимумы именно такие

Для действительного гармонического колебания `x(n) = A·cos(2πf n/Fд)`, попадающего точно на сетку ДПФ (`f = k₁·Δf`), модуль коэффициентов ДПФ равен нулю везде, кроме двух отсчётов:

```text
|X(k₁)| = |X(N − k₁)| = A·N/2,
Δf = Fд / N = 10 000 / 1024 = 9,765625 Гц.
```

### Одна гармоника (первый эксперимент)

```text
A₁ = 1,24;  f₁ = 1250 Гц;  k₁ = 1250 / 9,765625 = 128;
|X(128)| = |X(896)| = 1,24·1024/2 = 634,88.
```

### Сумма гармоник (второй эксперимент)

```text
A₁ = 1,24;  f₁ = 1250 Гц (k = 128 и 896)  → 634,88;
4A₂ = 9,92; f₂ = 625 Гц (k = 64 и 960)    → 9,92·512 = 5079,04.
```

Отсчёт `N − k = 896` (или `960`) — зеркальный: он соответствует отрицательной частоте действительного сигнала и имеет тот же уровень. Уровни относятся друг к другу как `5079,04 / 634,88 = 8`, что совпадает с отношением амплитуд `4A₂ / A₁ = 9,92 / 1,24 = 8`.

## Импульсная последовательность

Ширина импульса — 16 отсчётов, период повторения — 1024. Модуль ДПФ описывается ядром Дирихле, его нули расположены там, где `sin(π·16k/N) = 0`, то есть при

```text
k = 64m  →  f = 625m Гц: 625, 1250, 1875, 2500, …, 4375 Гц.
```

Проверено численно:

```text
X(0) = 16;  |X(64)| = |X(128)| = |X(192)| = 0;
первый боковой лепесток max |X(92)| = 3,5214 (f = 898,4 Гц).
```

На спектрограммах (рис. 6 и 7) нули отмечены синими штриховыми линиями ровно в провалах: 625, 1250, 1875, 2500, 3125, 3750, 4375 Гц. В логарифмическом масштабе провалы уходят до −90 дБ — это предел шкалы спектроанализатора.

Фаза ДПФ импульса:

```text
φ(k) = −15πk/N + (π, если ядро Дирихле отрицательно),
```

поэтому внутри лепестка фаза линейна, а в нулях модуля претерпевает перескок на π.

## Как проверить расчёт в Python

```python
import numpy as np
N, Fd = 1024, 10_000
n = np.arange(N)

single = 1.24 * np.cos(2*np.pi*1250*n/Fd)
total  = single + 4*2.48 * np.cos(2*np.pi*625*n/Fd)

print(np.abs(np.fft.fft(single))[[128, 896]])   # [634.88 634.88]
print(np.abs(np.fft.fft(total))[[64, 960, 128, 896]])
# [5079.04 5079.04  634.88  634.88]

pulse = np.zeros(N); pulse[:16] = 1
mag = np.abs(np.fft.fft(pulse))
print(mag[0], mag[[64, 128, 192]], mag[92])     # 16.0  [0 0 0]  3.5214
```
