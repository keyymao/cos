# Исходники ЛР №7 (вариант 24 / зачётка 53)

ДПФ и БПФ Кули–Тьюки с прореживанием по времени. Отчёт оформлен по структуре примера `примеры/лаба5/лаба №5.pdf` и требованиям `лабораторные/лаба7/LR_TsOS_7_DPF.pdf`; все коэффициенты и рисунок графа БПФ рассчитаны заново для варианта 24 / зачётки 53.

## Запуск из корня репозитория

```bash
python3 расчёт/lab7_24_53/calculate.py  # ДПФ/БПФ, проверки, JSON/CSV и TXT
python3 расчёт/lab7_24_53/figures.py    # граф БПФ -> расчёт/lab7_24_53/assets/
python3 расчёт/lab7_24_53/build_docx.py # DOCX -> лабораторные/лаба7/
python3 расчёт/lab7_24_53/build_pdf.py  # PDF  -> лабораторные/лаба7/
```

## Зависимости

```bash
pip install numpy scipy matplotlib python-docx reportlab pymupdf pillow lxml
```

`numpy` используется для независимого контроля, `scipy`/`matplotlib` — для рисунков, `pymupdf` и `pillow` — для визуальной проверки готового PDF.

## Параметры варианта

`Fд = 2000(Nбр mod 5 + 1) = 10000 Гц`, `T = 0,0001 с`, `A1 = 1 + 0,01·24 = 1,24`, `A2 = 2A1 = 2,48`, `f1 = Fд/8 = 1250 Гц`, `f2 = Fд/16 = 625 Гц`, `N = 1024`, домашняя последовательность по таблице 2 методички — `x(n) = [0 0 0 1 1 1 1 0]`.

## Файлы

| Файл | Назначение |
|---|---|
| `calculate.py` | Прямое ДПФ, рекурсивное БПФ, промежуточные последовательности, гармоники и прямоугольный импульс |
| `figures.py` | Граф БПФ Кули–Тьюки (рисунок 1 отчёта); остальные функции — вспомогательные, по умолчанию не строятся |
| `content.py` | Единое содержание отчёта для DOCX и PDF |
| `build_docx.py` | Сборка DOCX с формулами Word/OMML |
| `build_pdf.py` | Сборка PDF через ReportLab |
| `variant_data_lab7_24_53.json` | Исходные данные, ДПФ, промежуточные этапы, пики и ошибки проверок |
| `dft_8point_24_53.csv` | `k; Re X(k); Im X(k); \|X(k)\|; phase` для домашней последовательности |
| `assets/` | Сгенерированные рисунки отчёта |

Общий модуль формул `mathast.py` находится в родительской папке `расчёт/`.

## Проверки и согласования

- Прямое матричное ДПФ и рекурсивное БПФ сравниваются с `numpy.fft.fft`; максимальные расхождения — `3,78·10⁻¹⁵` и `3,14·10⁻¹⁶`.
- Аналитические коэффициенты ДПФ-8, обратное ДПФ, сопряжённая симметрия и все четыре операции объединения последнего этапа проверяются утверждениями в `calculate.py`.
- Пики гармоник сверяются с `A·N/2`: `634,88` (одна гармоника `A1`), `1269,76` (`A2`) и `5079,04` (усиление 4).
- Для прямоугольного импульса проверяются `X(0) = 16`, нули при `k = 64m` и равенство Парсеваля.

## Оформление

Скриншоты «Спектр-2» в отчёт не включались: в экспериментальной части на месте рисунков 2–9 стоят заглушки `[место для скриншота из «Спектр-2»]` с подписями по образцу `лаба5.pdf`. Набор разделов повторяет образец: титул, ЦЕЛЬ РАБОТЫ, ИСХОДНЫЕ ДАННЫЕ, ДОМАШНИЙ РАСЧЁТ, ЭКСПЕРИМЕНТАЛЬНАЯ ЧАСТЬ, ВЫВОД — без списка источников и дополнительных пунктов.
