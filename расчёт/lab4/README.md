# Исходники ЛР №4 (вариант 12 / зачётка 06)

ФВЧ Баттерворта, n = 6. Аналоговый ФНЧ-прототип берётся из ЛР №3 и переводится в цифровой ФВЧ преобразованием Константинидиса с предыскажением. Рисунки не строятся: моделирование в «Спектр-2» выполняется пользователем самостоятельно.

## Запуск

```bash
cd расчёт/lab4
python3 calculate.py     # расчёт, проверки, JSON/CSV/TXT для Спектр-2
python3 build_docx.py    # отчёт .docx -> ../../лабораторные/лаба4/
python3 build_pdf.py     # отчёт .pdf  -> ../../лабораторные/лаба4/
```

## Зависимости

```bash
pip install numpy scipy python-docx reportlab pymupdf lxml matplotlib
```

## Файлы

| Файл | Назначение |
|---|---|
| `calculate.py` | расчёт прототипа, преобразование Константинидиса, проверки, выгрузка коэффициентов |
| `variant_data_lab4.json` | все вычисленные величины и результаты проверок |
| `coefficients_lab4.csv` | коэффициенты звеньев и знаки для «Спектр-2» |
| `content.py` | содержание отчёта, единый источник для .docx/.pdf |
| `build_docx.py` | сборка Word-отчёта с формулами OMML |
| `build_pdf.py` | сборка PDF через ReportLab |

Общий `mathast.py` используется из родительской папки `расчёт/`.

## Ключевые коэффициенты

```text
Fд = 12400 Гц, F1(ПП) = 3740 Гц, F3(ПЗ) = 1440 Гц
C = tg(π·3740/12400) = 1.3911513609
K = 0.0187949819

звено 1: a1 = 0.14692140, a2 = 0.02254545
звено 2: a1 = 0.16906057, a2 = 0.17662994
звено 3: a1 = 0.22876872, a2 = 0.59218744
```

В «Спектр-2» обратные связи вводятся как `−a1`, `−a2`.

Проверка: `a(3740) = 0.4455 дБ`, `a(1440) = 57.7025 дБ`, `max|полюс| = 0.76953716 < 1`.
