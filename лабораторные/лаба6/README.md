# Лабораторная работа №6

В папке два варианта: **12 / зачётка 06** (ФВЧ) и **24 / зачётка 53** (ФНЧ).
Тип фильтра определяется последней цифрой номера зачётки: нечётная (3) — ФНЧ, чётная (6) — ФВЧ.

**Тема:** синтез цифровых КИХ-фильтров методом окон с применением окна Кайзера.

## Вариант 12, зачётка 06

**Фильтр:** ФВЧ, `Fд = 10600 Гц`, `F1 = 2520 Гц`, `F3 = 1005 Гц`, `R = 16`, `N = 17`, `β = 3,39532105`.

- [Методические указания](LR_TsOS_6_KIKh_KAJZER.pdf)

Отчёт содержит исходные данные, домашний расчёт, таблицу 17 коэффициентов, графики ИХ и АЧХ, проверку минимальности порядка, структурную схему, численное моделирование, порядок действий в «Спектр-2» и вывод.

### Результаты проверки

- В полосе задержания `0…1005 Гц`: `max |H| = 0,009669005 ≤ 0,01`.
- В полосе пропускания `2520…5300 Гц`: `0,990391456…1,005886154`, допуск `0,95…1,05` выполнен.
- На частоте среза `1762,5 Гц`: `|H| = 0,500312735`.
- Порядок `R = 16` минимальный среди чётных порядков, при которых выполняются требования.

Исходники расчёта и повторной сборки: [`../../расчёт/lab6/`](../../расчёт/lab6/). Рисунки АЧХ/ИХ получены численным моделированием; скриншоты интерфейса «Спектр-2» в отчёт не включались.
