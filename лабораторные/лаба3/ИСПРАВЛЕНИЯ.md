## 5. Порядок расчёта и правило округления

Чтобы все числа в тексте можно было повторить на бумаге, принят единый порядок:

1. Промежуточные величины считаются по формулам и округляются **в момент записи** (5 знаков после запятой — для полюсов, a, b, c0…c2; 4 знака — для a1, a2; 3 знака — для ∏c0).
2. В следующие формулы подставляются **уже записанные** (округлённые) значения — так расчёт воспроизводится вручную:
   - sh β = 0,31007, ch β = 1,04697 → p₁ = −0,31007·0,25882 + j·1,04697·0,96593 = −0,08025 + j1,01130;
   - a = −2·(−0,08025) = 0,16050; b = 0,08025² + 1,01130² = 1,02917;
   - A = 2·1,0610343 = 2,12207; A² = 2,12207² = 4,50318; a·A = 0,16050·2,12207 = 0,34059;
   - c0 = 4,50318 + 0,34059 + 1,02917 = 5,87294; c1 = −2·4,50318 + 2·1,02917 = −6,94802; c2 = 4,50318 − 0,34059 + 1,02917 = 5,19176;
   - a1 = c1/c0 = −1,1831; a2 = c2/c0 = 0,8840.
3. Округление — до ближайшего, знак минус у коэффициентов a1 сохраняется (в схеме «Спектр-2» он вводится как −a1).
