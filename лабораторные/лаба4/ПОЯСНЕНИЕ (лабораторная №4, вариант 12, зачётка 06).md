## Главные результаты расчёта

Интервал дискретизации:

```text
T = 1 / 12400 = 0,00008064516129 с = 80,64516129 мкс
```

Константа преобразования Константинидиса для ФВЧ:

```text
C = tg(π · F1 / Fд) = tg(π · 3740 / 12400) = 1,3911513609
C² = 1,9353021091
```

Подстановка:

```text
p = C · (1 + z⁻¹) / (1 − z⁻¹)
```

Общий коэффициент усиления:

```text
K = 0,0187949819
```

## Коэффициенты звеньев

Передаточная функция одного звена:

```text
H_i(z) = (1 − z⁻¹)² / (1 + a1_i z⁻¹ + a2_i z⁻²)
```

То есть:

```text
b0 = 1, b1 = −2, b2 = 1, a0 = 1
```

| Звено | a1 | a2 | В «Спектр-2»: −a1 | В «Спектр-2»: −a2 |
|---:|---:|---:|---:|---:|
| 1 | 0,14692140 | 0,02254545 | −0,14692140 | −0,02254545 |
| 2 | 0,16906057 | 0,17662994 | −0,16906057 | −0,17662994 |
| 3 | 0,22876872 | 0,59218744 | −0,22876872 | −0,59218744 |

**Важно:** в методичке для «Спектр-2» сказано, что коэффициенты `a`, кроме `a0`, вносятся в усилитель с противоположным знаком. Поэтому в обратной связи нужны именно отрицательные числа из последних двух столбцов.

Если поле допускает только 6 знаков после запятой:

| Звено | −a1 | −a2 |
|---:|---:|---:|
| 1 | −0,146921 | −0,022545 |
| 2 | −0,169061 | −0,176630 |
| 3 | −0,228769 | −0,592187 |

При таком округлении рекомендуется взять `K = 0,018795` — тогда расчётное ослабление на 3740 Гцоколо 0,445496 дБ, требование выполняется.

### Почему на 1440 Гц не ровно 40 дБ

В ЛР №4 по методичке используется уже рассчитанный в ЛР №3 аналоговый ФНЧ-прототип n = 6. Предыскажение отображает границу ПЗ 1440 Гц в нормированную частоту прототипа:

```text
Ω(1440) = C · ctg(π · 1440 / 12400) = 3,64244994
```

Это больше прежней нормированной границы 2,59722, поэтому ослабление получается с запасом: 57,7025 дБ вместо минимально требуемых 40 дБ.

Если на графике искать точку ровно −40 дБ, она будет около:

```text
f ≈ 1943,36 Гц
```

Это не ошибка: заданная полоса задержания заканчивается на 1440 Гц, и там ослабление должно быть **не меньше** 40 дБ.

## Настройки для «Спектр-2»

- Частота дискретизации системы: `12400 Гц`.
- Структура: три биквадратных звена прямой формы I, соединённые каскадно.
- Прямая ветвь каждого звена: `b0 = 1`, `b1 = −2`, `b2 = 1`.
- Обратная связь каждого звена: усилители `−a1`, `−a2` из таблицы выше.
- Общий усилитель: `K = 0,0187949819` отдельно перед каскадом или после него.
- ГТИ: период = размер пачки системы; ширина импульса = 1.
- Для АЧХ добавить спектроанализатор; для ИХ при необходимости осциллограф.
