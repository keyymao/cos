# Старые версии лабораторных

Архив прежних, ещё не принятых версий. Содержимое перенесено сюда без удаления отчётов и вспомогательных материалов.

| Папка | Что хранится |
|---|---|
| [`лаба3/`](лаба3/) | Методические указания, DOCX/PDF двух вариантов, пояснение и история исправлений. |
| [`лаба4/`](лаба4/) | Методические указания, DOCX/PDF двух вариантов, пояснение и коэффициенты. |
| [`лаба6/`](лаба6/) | Методические указания, DOCX/PDF двух вариантов, коэффициенты и описание расчёта. |
| [`лаба7/`](лаба7/) | Методические указания, DOCX/PDF двух вариантов, параметры и описание расчёта. |

Новые сборки должны сохраняться не сюда, а в [`../текущие/`](../текущие/). Финальные проверенные версии предназначены для [`../исправленые/`](../исправленые/).
