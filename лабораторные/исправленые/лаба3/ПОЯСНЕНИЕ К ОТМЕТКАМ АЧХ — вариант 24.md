## Какие частоты нужно отмечать

В исходных данных указаны частоты аналогового прототипа:

```text
F₁ = 2220 Гц
F₃ = 3760 Гц
```

После билинейного преобразования частоты искажаются. В разделе 1.8 отчёта уже вычислены граничные частоты цифрового фильтра:

```text
f₁ = 2074,6 Гц — граница полосы пропускания;
f₃ = 3173,3 Гц — граница полосы задержания.
```

Поэтому на экспериментальных АЧХ отмечены именно `2074,6` и `3173,3 Гц`.

## Уровни для линейного масштаба

Максимальное допустимое ослабление в полосе пропускания:

```text
|H|ₘᵢₙ = 10^(−aₘₐₓ/20)
        = 10^(−0,4455/20)
        = 0,950003 ≈ 0,95.
```

Следовательно, после нормирования максимума АЧХ к единице в полосе пропускания должно выполняться:

```text
0,95 ≤ |H| ≤ 1.
```

Минимальное требуемое подавление в полосе задержания:

```text
|H|ₘₐₓ,ПЗ = 10^(−aₘᵢₙ/20)
           = 10^(−40/20)
           = 0,01.
```

То есть в полосе задержания должно выполняться:

```text
|H| ≤ 0,01.
```

Вертикальная шкала скриншота «Спектр-2» зависит от амплитуды тестового сигнала, поэтому уровни нанесены **относительно максимума в полосе пропускания**. Синяя область соответствует `0,95…1`, красная линия — уровню `0,01`.

По коэффициентам таблицы 3 и коэффициенту усиления `K = 0,0004522`:

## Если нужно нарисовать самостоятельно в Python

Минимальный набор команд после построения массива частот `f` и модуля `H`:

```python
plt.axvline(2074.6, color="tab:blue", ls="--", label="f₁ = 2074,6 Гц")
plt.axvline(3173.3, color="tab:red",  ls="--", label="f₃ = 3173,3 Гц")

# Для линейной АЧХ:
plt.hlines(0.95, 0, 2074.6, color="tab:blue", ls=":")
plt.hlines(0.01, 3173.3, 7400, color="tab:red", ls=":")
plt.fill_between([0, 2074.6], 0.95, 1.0, color="tab:blue", alpha=0.12)
plt.fill_between([3173.3, 7400], 0.0, 0.01, color="tab:red", alpha=0.12)
```
