## Результат задания №3

| Параметр | По АЧХ цифрового фильтра | Аналоговый фильтр по ТЗ | Сравнение |
|---|---:|---:|---|
| Граница полосы пропускания | `f₁ ≈ 2220 Гц` при `a = 0,4455 дБ` | `F₁ = 2220 Гц` | практически совпадает |
| Граница полосы задержания | `f₃ ≈ 3261 Гц` при `a = 40 дБ` | `F₃ = 3760 Гц` | требуемое подавление достигается примерно на `499 Гц` раньше |
| Ослабление при `3760 Гц` | `53,35 дБ` | требуется не менее `40 дБ` | запас `13,35 дБ` |

Предыскажение точно сохранило заданную границу полосы пропускания. То, что уровень 40 дБ достигается раньше `F₃`, не нарушает техническое задание: на самой заданной частоте подавление уже больше требуемого.
