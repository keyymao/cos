## Что отмечено на графике АЧХ

Ось частот скриншота не начинается с нуля: по зелёным подписям курсоров видимый диапазон
`948,61…5042,19 Гц` (курсор `2972,27 Гц` стоит на `x = 927`, что совпадает с первым нулём
АЧХ). Одна большая клетка по вертикали — 10 дБ ≈ 60,8 px; уровни отсчитаны **вниз от
максимума в ПП**, потому что абсолютная шкала «Спектроанализатора» зависит от амплитуды
тестового импульса (`-50…-160 дБ` на экране).

| Элемент разметки | Что означает |
|---|---|
| синяя закрашенная зона, жирный пунктир | ПП `0…F₁ = 1305 Гц` (видна с 949 Гц) |
| красная закрашенная зона, жирный пунктир | ПЗ `F₃ = 2940 Гц…Fд/2 = 5600 Гц` (видна до 5042 Гц) |
| синий горизонтальный пунктир | уровень `|H| = 0,95` (`aₘₐₓ = 0,4455 дБ`) |
| красный горизонтальный пунктир | уровень `|H| = 0,01` (`aₘᵢₙ = 40 дБ`) |
| тонкий штрихпунктир + маркеры | фактические границы `f₁ ≈ 1494 Гц`, `f₃ ≈ 2908 Гц` |
| серый штрихпунктир | частота разрыва `Fc = 2122,5 Гц`, `|H| ≈ 0,5` |

## Ключевые числа (по коэффициентам из `расчёт/lab6_24_53/`)

```text
Fд = 11200 Гц; F₁ = 1305 Гц; F₃ = 2940 Гц; Fc = 2122,5 Гц
δ₁ = 0,05 → 0,95…1,05; δ₂ = 0,01 → a ≥ 40 дБ
R = 16; N = 17; β = 3,395321; групповая задержка = 8 отсчётов
```

| Точка | Значение | Сравнение с ТЗ |
|---|---:|---|
| Пересечение `|H| = 0,95` | `f₁ = 1493,6 Гц` | на 189 Гц дальше `F₁` (14,5 %) |
| Пересечение `|H| = 0,01` | `f₃ = 2907,8 Гц` | на 32 Гц раньше `F₃` (1,1 %) |
| `|H(F₁)|` | `0,996462` (`0,031 дБ`) | внутри `0,95…1,05` |
| `|H(F₃)|` | `0,004758` (`46,45 дБ`) | запас `6,45 дБ` к `40 дБ` |
| `|H(Fc)|` | `0,499279` | ≈ 0,5, как у идеальной АЧХ |
| Максимум лепестков в ПЗ | `0,009074` (`40,84 дБ`, `3154 Гц`) | ≤ `0,01` |

Расхождение границ — не ошибка, а запас, который даёт окно Кайзера при минимальном
чётном порядке `R = 16`; заданные `F₁` и `F₃` лежат внутри областей, где допуски
заведомо выполняются.

## Характер ИХ (задание №4)

На рисунке 2 осциллограмма соединяет отсчёты прямыми, поэтому плавная кривая — лишь
интерполяция 17 дискретных значений. ИХ конечна (`b(0)…b(16)`, дальше нули), симметрична
относительно `b(8) = 0,379018`, знакопеременна, затухает к краям (`b(0) = b(16) = −0,000593`
из-за окна `w(±8) = 0,1480`). Это КИХ-фильтр I типа с линейной ФЧХ и задержкой
`τ = R/2 = 8 отсчётов = 0,714 мс`; форма совпадает с расчётным графиком домашнего задания.
