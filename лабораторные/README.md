# Лабораторные работы

Лабораторные №3, 4, 6 и 7 разделены по степени готовности, чтобы старые отчёты не смешивались с рабочими и окончательными версиями.

## Папки по статусам

| Статус | Содержимое | Правило |
|---|---|---|
| [`старые/`](старые/) | Прежние отчёты, методические указания, пояснения и вспомогательные TXT. | Архив: не перезаписывать при новой сборке. |
| [`текущие/`](текущие/) | Почти исправленные рабочие версии. | Сюда направлен вывод скриптов из [`../расчёт/`](../расчёт/). |
| [`исправленые/`](исправленые/) | Окончательно доработанные отчёты ЛР №3 и №4 для вариантов 12/06 и 24/53, а также ЛР №6 для варианта 12/06. | Переносить сюда только проверенную версию. |

## Одинаковая структура каждого статуса

```text
<статус>/
├── лаба3/
├── лаба4/
├── лаба6/
└── лаба7/
```

Архив заполнен прежними файлами. В `текущие/` находятся загруженные рабочие версии. В `исправленые/лаба3/` и `исправленые/лаба4/` лежат доработанные варианты 12/06 и 24/53 с отмеченными параметрами АЧХ, а в `исправленые/лаба6/` — исправленный вариант 12/06 с выполненными заданиями №3 и №4. Остальные пустые рабочие папки содержат отслеживаемые заготовки и не потеряются в Git.

PDF-примеры находятся отдельно в [`../примеры/`](../примеры/). Полная схема и таблица исходников приведены в [корневом README](../README.md).
