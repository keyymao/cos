# Лабораторные работы

Лабораторные №3, 4, 6 и 7 разделены по степени готовности, чтобы старые отчёты не смешивались с рабочими и окончательными версиями.

## Папки по статусам

| Статус | Содержимое | Правило |
|---|---|---|
| [`старые/`](старые/) | Прежние отчёты, методические указания, пояснения и вспомогательные TXT. | Архив: не перезаписывать при новой сборке. |
| [`текущие/`](текущие/) | Почти исправленные рабочие версии. | Сюда направлен вывод скриптов из [`../расчёт/`](../расчёт/). |
| [`исправленые/`](исправленые/) | Заготовки для окончательно проверенных отчётов. | Переносить сюда только принятую финальную версию. |

## Одинаковая структура каждого статуса

```text
<статус>/
├── лаба3/
├── лаба4/
├── лаба6/
└── лаба7/
```

Архив уже заполнен прежними файлами. В `текущие/` и `исправленые/` добавлены отслеживаемые заготовки с краткими инструкциями, поэтому пустые рабочие папки не потеряются в Git.

PDF-примеры находятся отдельно в [`../примеры/`](../примеры/). Полная схема и таблица исходников приведены в [корневом README](../README.md).
