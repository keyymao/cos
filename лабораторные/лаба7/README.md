# Лабораторная работа №7 — вариант 12, зачётка 06

**Тема:** дискретное преобразование Фурье. Алгоритм быстрого преобразования Фурье Кули–Тьюки.

**Параметры:** `N = 1024`, `Fд = 6000 Гц`, `A1 = 1,12`, `A2 = 2,24`, `f1 = 750 Гц`, `f2 = 375 Гц`.

Отчёт на 12 страницах содержит прямой расчёт ДПФ последовательности `[0, 1, 1, 1, 0, 0, 1, 1]`, промежуточные ДПФ-2/ДПФ-4, граф БПФ, проверку вычислительной сложности, спектры одной и двух гармоник, ДПФ прямоугольного импульса и спектрограмму.

## Основные контрольные значения

- `X(0) = 5`, `X(1) = (1 − j)/√2`, `X(2) = −2 + j`, `X(4) = −1`; остальные значения связаны сопряжённой симметрией.
- Одиночная гармоника `A1`: пики `573,44` при `k = 128` и `896`.
- Сумма с амплитудой `A2`: пики `1146,88` при `k = 64` и `960`.
- При дополнительном усилении второй ветви в 4 раза: пики `4587,52` при `k = 64` и `960`.
- Прямоугольный импульс шириной 16 отсчётов: `X(0) = 16`, нули при `k = 64m`, первый нуль — `375 Гц`.
