# Контрольные работы №1 и №2, вариант 10

Две отдельные работы по дисциплине «Цифровая обработка сигналов» для варианта 10:
каждая в формате Word (`.docx`) и PDF (`.pdf`). Оформление и структура повторяют
примеры `примеры/КР1_ЦОС_вариант2.pdf` (КР1) и `примеры/Отчет.pdf` (КР2);
задания КР1 — по бланку `Бланк-для-КР1-ЦОС (1).pdf` (13 заданий),
исходные коэффициенты — по таблице `Варианты_коэффицентов_передаточной_функции (1).pdf`.

## Состав

| Файл | Назначение |
|:---|:---|
| `Контрольная 1.docx`, `Контрольная 1.pdf` | КР №1 — рекурсивное звено 2-го порядка: ПФ, разностное уравнение, структурная схема, ИХ (по формуле и по РУ), карта нулей и полюсов, АЧХ/ФЧХ, качественный анализ и экспресс-анализ, графики, листинг программы. 4 рисунка, 5 таблиц, 23 формулы Word (OMML) |
| `Контрольная 2.docx`, `Контрольная 2.pdf` | КР №2 — система обработки аудиосигнала: спектр и спектрограмма, эквалайзер на три полосы, подавление тональной помехи режекторным БИХ-фильтром, синтез WAV. 7 рисунков, 4 таблицы, приложения с листингами |
| `src/` | исходники: расчёт, рисунки и сборка обоих документов (см. `src/README.md`) |

## Исходные данные варианта 10

Коэффициенты передаточной функции (таблица вариантов):

```text
b0 = 1;  b1 = −0,7234;  b2 = +0,4231;  a1 = 0,7234;  a2 = 0,9234
```

Примечание: в таблице вариантов для варианта 10 указано b₂ = −0,4231, но при таком
значении нуль z₁ = 1,106 выходит за единичную окружность. По согласованию в работе
принято b₂ = +0,4231 (модуль сохранён) — тогда все нули и полюсы лежат внутри
единичной окружности, звено минимально-фазовое. a₁, a₂ — без изменений.

КР2: fд = 16 000 Гц, 3,0 с (48 000 отсчётов), помеха 1500 Гц (амплитуда 0,30) и её
гармоника 3000 Гц (0,10); эквалайзер НЧ/СЧ/ВЧ = +6 / 0 / −6 дБ с границами 1000 и 3000 Гц;
режекторный фильтр Q = 35, двойной проход (filtfilt).

## Ключевые результаты

КР1:

- полюсы p = −0,3617 ± j0,8903 (r = 0,9609, φ* = 1,9567 рад = 0,6228π);
- нули z₁,₂ = 0,3617 ± j0,5406, |z| = 0,6505 — все особые точки внутри окружности;
- h(0…4) = 1,0000; −1,4468; 0,5463; 0,9408; −1,1850 — по формуле и по РУ совпадают
  (max|Δh| = 3·10⁻¹⁵ на n = 0…40);
- АЧХ/ФЧХ в пяти точках: (0 → 0,2644/0), (π/4 → 0,2382/0,9385), (π/2 → 1,2719/2,3629),
  (φ* → 19,2733/1,1613), (π → 1,7888/0);
- максимум АЧХ 19,29 при ω̄ ≈ 1,958; max|p| = 0,9609 < 1 — звено устойчиво;
- расчёт: 12/12 проверок PASS (в документ раздел проверки не включён).

КР2:

- помеха обнаружена на 1500,0 Гц (−11,7 дБ, превышение над «подложкой» 59,7 дБ ≥ 12 дБ);
- эквалайзер: измеренные усиления на 500 / 2000 / 5000 Гц = +6,00 / 0,00 / −6,00 дБ;
- режектор 1500 Гц: b₀ = b₂ = 0,992126, b₁ = a₁ = −1,649845, a₂ = 0,984252; уровень помехи
  −11,7 → −121,9 дБ (подавление 110,3 дБ); гармоника 3000 Гц подавлена на 119,3 дБ;
- ОСШ вне полосы помехи −3,4 → 26,2 дБ;
- выход `kr2_output.wav` — PCM 16 бит, 16 кГц, 48 000 отсчётов, 96 044 байта;
- расчёт: 9/9 проверок PASS (в документ раздел проверки не включён).
