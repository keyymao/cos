# Исходники контрольных работ №1 и №2 (вариант 10)

Скрипты пересчитывают все числа и заново собирают оба документа — и `.docx`, и `.pdf` —
из одних и тех же данных (`kr1_results.json`, `kr2/kr2_results.json`), поэтому отчёты
не могут разойтись с расчётом.

## Быстрый запуск

```bash
cd "контрольные 10 вариант/src"

# КР1: расчёт + 4 рисунка + kr1_results.json, затем сборка документов
python3 kr1_variant10.py
python3 make_kr1_docx.py          # -> ../Контрольная 1.docx и .pdf

# КР2: входной WAV, структурная схема, обработка, затем сборка документов
python3 kr2/make_architecture_fig.py  # figures/fig_architecture.png (рис. 1)
python3 kr2/make_input_signal.py
python3 kr2/kr2_signal_system.py --in kr2/kr2_input.wav --out kr2/kr2_output.wav
python3 make_kr2_docx.py          # -> ../Контрольная 2.docx и .pdf
```

Зависимости: `numpy scipy matplotlib python-docx reportlab lxml pillow`.
Формулы Word (OMML) собираются общим модулем `../../расчёт/mathast.py`.

## Файлы

| Файл | Назначение |
|---|---|
| `kr1_variant10.py` | расчёт всех 13 заданий КР1, рисунки `figures/fig1…4.png`, проверки (12/12 PASS) |
| `kr1_results.json` | все числа КР1 — единственный источник данных для отчёта |
| `make_kr1_docx.py` | содержание КР1 и сборка `.docx` + `.pdf` |

| `kr2/kr2_signal_system.py` | система: анализ → эквалайзер → режекция → синтез WAV; функции рисования помечены `# >>>plots` … `# <<<plots` и в листинг приложения не попадают |
| `kr2/make_architecture_fig.py` | рис. 1 — структурная схема системы (fig_architecture.png) |
| `kr2/kr2_results.json` | измеренные значения КР2 и результаты проверок |
| `make_kr2_docx.py` | содержание КР2 и сборка `.docx` + `.pdf` |
| `docblocks.py` | блоки документа (общее содержание для обоих форматов) |
| `docxkit.py` | рендерер Word: стили, OMML-формулы, таблицы, рисунки, листинги |
| `pdfkit.py` | рендерер PDF (ReportLab, DejaVu Serif); формулы — линейной записью |

## Исходные данные варианта 10

Коэффициенты ПФ: b₀ = 1; b₁ = −0,7234; b₂ = +0,4231; a₁ = 0,7234; a₂ = 0,9234.
В таблице вариантов для варианта 10 стоит b₂ = −0,4231, но тогда нуль z₁ = 1,106
выходит за единичную окружность; по согласованию b₂ взят по модулю (+0,4231), чтобы
все нули и полюсы были внутри окружности. a₁, a₂ — из таблицы без изменений.

КР2: fд = 16 000 Гц, 3,0 с (48 000 отсчётов); помеха 1500 Гц (0,30) и её гармоника
3000 Гц (0,10); эквалайзер НЧ/СЧ/ВЧ = +6 / 0 / −6 дБ (границы 1000 и 3000 Гц);
режектор Q = 35, двойной проход (filtfilt).
