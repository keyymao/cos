# Контрольные работы, вариант 10

Все задания для **варианта 10** по дисциплине «Цифровая обработка сигналов»:
две работы в формате Word (`Контрольная 1.docx`, `Контрольная 2.docx`).

## Состав

| Файл | Назначение |
|:---|:---|
| `Контрольная 1.docx` | КР №1 — все 13 заданий бланка (рекурсивное звено 2-го порядка, вариант 10): ПФ, РУ, структурная схема, ИХ (по формуле и по РУ), карта нулей/полюсов, АЧХ/ФЧХ, экспресс-анализ, 4 рисунка, OMML-формулы, проверка результатов, листинг программы |
| `Контрольная 2.docx` | КР №2 — система обработки аудиосигнала (структура как в примере «Контрольная 2 (вариант 23) — копия.pdf»): спектр и спектрограмма, эквалайзер 3 полосы, подавление тональной помехи режекторным БИХ-фильтром, синтез WAV; 7 рисунков, таблицы метрик, выводы, проверка результатов, приложения А/Б с листингами |

| `kr2_signal_system.py` | система КР2: `python kr2_signal_system.py --in kr2_input.wav --out output/kr2_output.wav` → WAV + 7 PNG в `output/` + консольный протокол |

| `output/` | результаты КР2: `kr2_output.wav` + 7 рисунков (в git не коммитятся, см. `.gitignore`) |
